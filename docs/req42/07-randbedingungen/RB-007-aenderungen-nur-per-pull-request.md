# RB-007: Entwicklungsprozess und Qualitätsprüfungen

**Entfallen als Randbedingung.** Branch-Regeln, Pull-Request-Pflicht und Qualitätsprüfungen vor dem Merge sind keine feste Randbedingung, sondern werden später in der Entwicklung festgelegt (Product Owner, 2026-11-20). Die ID wird nicht wiederverwendet. Bis dahin gilt die Freigaberegel für `docs/` aus [docs/README.md](../../README.md).
