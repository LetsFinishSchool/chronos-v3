# RB-001: Mehrsprachigkeit (Deutsch und Englisch)

Oberfläche **und** Benachrichtigungen (Push, E-Mail, ggf. Messenger) unterstützen mehrere Sprachen, zunächst Deutsch und Englisch. Weitere Sprachen müssen ohne Umbau ergänzbar sein. Die Sprache ist je Person einstellbar; für Gäste ohne Konto gilt die Sprache des Links bzw. Browsers (?). Texte dürfen nicht im Code verstreut sein. Der KI-Assistent ([F-015](../04-product-backlog/features/F-015-ki-assistent.md)) antwortet in der Sprache der Person. Code-Namen bleiben englisch.

Ersetzt die Alt-Annahme „alle UI-Texte sind deutsch“ aus chronos-root.
