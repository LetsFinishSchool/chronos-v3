# Z-010: Rückmeldungen automatisch einholen

**Ziel:** Ein Terminorganisator muss sich nie selbst darum kümmern, von allen Eingeladenen eine Rückmeldung zu bekommen; Teammitglieder werden automatisch erinnert.

**Vorteil:** Kein Nachfassen per Hand; die Leitung plant anhand der Antwortübersicht ([Z-001](Z-001-termine-abstimmen-und-teilnahme-nachverfolgen.md)).

**Metrik:** Anzahl manueller Nachfass-Aktionen der Leitung je Termin: Soll 0 (kein Werkzeug zum Nachfassen nötig). Die Erinnerungen bleiben im Benachrichtigungsbudget ([Z-009](Z-009-benachrichtigungen-sparsam-halten.md)).
