# FA-018: Kostenerfassung

**Akzeptanzkriterien:**
1. Jeder kostenverursachende Aufruf erzeugt einen Posten mit Benutzer oder Team, Auslöser, Anbieter, Zeitpunkt, Menge und Betrag.
2. Die Summe je Benutzer/Team lässt sich in Einzelposten aufschlüsseln.
3. Kann ein Aufruf keinem Benutzer zugeordnet werden, wird er dem Team zugeordnet; unzuordenbare Posten gibt es nicht.
4. Auch fehlgeschlagene, aber berechnete Aufrufe werden erfasst.
