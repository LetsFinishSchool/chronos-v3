# FA-007: Labels für Rollen und Aufgaben

**Akzeptanzkriterien:**
1. Ein Label ist freier Text, keine feste Liste; einer Person können beliebig viele Labels zugewiesen werden.
2. Ein Label hat genau einen Geltungsbereich (Team, Unter-Team, Veranstaltung oder Termin).
3. Labels sind für alle Mitglieder des Bereichs sichtbar und ändern keine Berechtigungen ([M-002](../../05-modelle/M-002-berechtigungen.md)).
