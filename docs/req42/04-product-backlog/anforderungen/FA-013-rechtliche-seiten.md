# FA-013: Rechtliche Seiten

**Akzeptanzkriterien:**
1. Impressum und Datenschutzerklärung sind ohne Anmeldung erreichbar.
2. Die Datenschutzerklärung beschreibt nur Verarbeitungen, die das System tatsächlich ausführt ([Z-007](../../01-ziele/Z-007-datensparsam-und-datenschutzkonform-betreiben.md)).
