# F-011: Anmeldung und Konto

**Story:** Als Mitglied möchte ich mich über Keycloak anmelden, damit ich ein dauerhaftes Konto habe.

**Umfang:**
- Anmeldung und Registrierung über Keycloak
- Anzeigename und Profil
- Übernahme einer vorherigen Gast-Identität (Antworten, Nachrichten) beim Registrieren über denselben Link

**Entscheidung:** Ein Gast kann sein bisheriges Handeln bei der Registrierung über denselben Link in sein Konto übernehmen; Datenschutzprüfung in [RA-007](../../12-risiken-annahmen/RA-007-einladungslinks-und-gast-identitaet.md).
