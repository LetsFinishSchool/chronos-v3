# F-006: Terminfindung per Abstimmung

**Story:** Als Leitungsteam-Mitglied möchte ich mehrere Terminvorschläge zur Abstimmung stellen, damit das Team einen gemeinsamen Termin findet.

**Umfang:**
- Terminfindung mit Terminvorschlägen anlegen
- Abstimmung über jeden Vorschlag
- Vorschlag festlegen, daraus entsteht ein Termin

**Entscheidung:**
- Antwortskala je Vorschlag: Ja / Vielleicht / Nein.
- Wer darf festlegen? Alle Mitglieder (Gleichberechtigung)
